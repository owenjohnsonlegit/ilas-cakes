Cakes by Ila 🎂

A simple, mobile-first portfolio website for Cakes by Ila, showcasing Ila’s custom wedding cakes, birthday cakes, and other creations.

About

The site is designed to give customers an easy way to:

* Browse Ila’s cake portfolio
* Learn more about Ila and her work
* See how the ordering process works
* Find answers to common questions
* Submit a custom cake request

Tech

* Static HTML, CSS, and JavaScript
* Hosted with Cloudflare Pages
* GitHub for source control and deployment
* Formspree for cake request submissions

Design

The site uses a warm, minimal boutique-bakery aesthetic with cream, sage, and blush colors, elegant typography, and a strong focus on Ila’s cake photography.

The website is designed mobile-first and optimized for performance, accessibility, and simplicity.

Deployment

Changes pushed to the production branch are automatically deployed through Cloudflare Pages.
